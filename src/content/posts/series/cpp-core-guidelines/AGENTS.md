# C++ Core Guidelines 시리즈 규칙

이 폴더와 하위 폴더의 원고에 적용한다. 공통 문체와 humanizer 퇴고, 퇴고 후 문맥 검토는 상위 `src/content/AGENTS.md`를 따른다. 이 문서의 경로는 저장소 루트를 기준으로 한다.

## 원문과 예제

- 해당 회차에서 다루는 공식 규칙의 이유, 예외, 검사 방법을 확인하고 본문에 원문 링크를 둔다.
- 예제에 필요한 C++ 표준 버전을 명시한다. 실행 가능한 예제와 설명용 코드 조각, 의도적으로 컴파일에 실패하는 코드를 구분한다.
- 실행 결과를 제시하는 코드는 실제로 컴파일하고 실행한다. 검증 환경과 결과는 `docs/series/cpp-core-guidelines/`에 기록한다.

## 연재 관리

- 회차별 범위와 기존 검증 기록은 `docs/series/cpp-core-guidelines/`에서 확인한다.
- 파일명은 `01-reading-guide.md`처럼 회차 번호로 시작한다. `slug`는 `cpp-core-guidelines-01-reading-guide`처럼 시리즈와 회차를 포함하며 발행 후 유지한다.
- 글을 추가하면 관련 목차와 이전·다음 글 링크를 갱신한다. 링크는 발행된 글에만 연결한다.
