Windows에서 “앱을 다운로드하여 이 'gbtdllib' 링크를 여세요”라는 팝업이 표시됐습니다. 창에는 Microsoft Store에서 앱을 찾으라는 안내가 나왔습니다.

사용 중인 PC에서는 GIGABYTE Control Center(GCC)를 재설치한 뒤 `gbtdllib` 팝업이 나타나지 않았습니다.

<img src="/images/posts/gbtdllib-popup.png" width="743" height="404" alt="gbtdllib 링크를 열 수 있는 앱이 없다며 Microsoft Store 검색을 제안하는 Windows 팝업" />

## GIGABYTE Control Center 재설치

1. Windows 설정 → 앱 → 설치된 앱에서 GIGABYTE Control Center를 찾아 제거합니다.
2. GIGABYTE 공식 사이트에서 설치 파일을 내려받아 GCC를 다시 설치합니다.
