# C++ Core Guidelines 시리즈 규칙

이 폴더와 하위 폴더의 글에 적용한다. [공통 작성 규칙](../../AGENTS.md)을 함께 따른다.

## 해설과 출처

- C++ Core Guidelines의 권고를 쉬운 말로 설명한다. 공식 원문을 확인하고 적용 조건과 예외를 유지한다.
- 예시의 상황과 대상을 먼저 소개한 뒤 용어, 인자, 동작을 설명한다.
- 권고 내용을 직접 서술하고 문장 끝에 규칙 번호를 첨자 링크로 붙인다. 링크는 해당 규칙의 공식 원문으로 연결한다.
- 예: `복잡한 저수준 처리는 인터페이스 안에 모으는 게 좋다.<sup>[P.11](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#rp-library)</sup>`

## 코드 예시

- 해설에 필요한 코드만 발췌한다. 설명과 무관한 헤더, 진입 함수, 입출력 코드는 생략한다.
- 생략으로 의미가 달라지지 않도록 필요한 선언과 전제 조건을 남긴다. 특정 C++ 표준 버전이 필요한 기능은 그 조건을 밝힌다.
- 예제의 정확성은 확인한다. 컴파일 확인 여부나 검증 환경을 본문에 적지 않고, 검증용 전체 코드와 기록도 별도 산출물로 만들지 않는다.
