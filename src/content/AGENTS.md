# 포스트 작성 규칙

`posts/`의 글을 작성하거나 수정할 때 적용한다.

## description

- 글의 주제와 독자가 얻을 핵심 내용을 한 줄로 요약한다. 제목에서 생략한 도구나 절차가 중요하면 요약에 포함한다.
- 마지막 단어는 내용에 맞는 명사로 쓴다. ‘생성’, ‘설정’, ‘오류별 조치’처럼 구체적으로 끝내고 ‘알아봅니다’, ‘방법입니다’ 같은 소개 문구는 생략한다.
- 끝에 마침표를 붙이지 않고 쉼표와 괄호도 최소화한다. 명령어나 파일명에 필요한 기호는 원래 표기를 유지한다.
- 예시: `Windows 11 KMS 인증 배치 파일의 관리자 권한 실행과 오류별 조치`
