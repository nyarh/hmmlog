# 포스트 공통 작성 규칙

`posts/`의 모든 글에 적용한다.

- 간결하고 건조한 한다체로 쓴다. 코드와 직접 인용은 원문을 유지한다.
- 핵심을 먼저 밝히고 짧고 구체적인 문장으로 설명한다.
- 과장, 상투어, 불필요한 수식어와 반복을 덜어낸다. 억지 대조와 형식적인 도입·마무리를 피한다.
- 예시와 용어에 필요한 배경을 먼저 설명한다. 이해에 필요한 전제와 조건은 생략하지 않는다.
- 작성 후 humanizer 스킬의 `SKILL.md`를 참고해 퇴고한다. 문체를 다듬을 때 사실, 코드, 링크와 메타데이터를 보존한다.
- 퇴고 후 전체를 다시 읽고 문맥이 어색한 부분을 고친다. 고친 문단은 앞뒤 문단과 함께 다시 읽는다.
